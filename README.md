# Memory Flip Game 🎴

A simple memory card matching game built using HTML, CSS, and JavaScript.

## How to Play

- Click on two cards to flip them.
- If they match, they stay flipped.
- If not, they flip back.
- Match all pairs to win!

## Technologies Used

- HTML
- CSS
- JavaScript
